## Roadmap

Planned work, not yet built.

- **Email delivery for invitations —** Invite tokens work, but there is no email service yet; the invitation link is returned in the API response. Add email delivery so invitees receive the link directly.

- **Employee removal —** Decide how to preserve messages that reference an employee as their sender, and prevent removal of the last admin so a business cannot be locked out.

- **AI agent —** Build the core feature that answers customer messages automatically.

- **WhatsApp integration —** Add a webhook to receive real WhatsApp messages and create customers from incoming phone numbers.
